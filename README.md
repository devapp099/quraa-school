# قُرعة — منصة الاختيار المدرسي

إصدار 1.0.0 مستقل لمدرسة نفيسة بنت أمية للبنات (١٠–١٢).

## التشغيل

حمّلي المستودع عبر Code → Download ZIP، وفكّي الضغط ثم افتحي `index.html` مباشرة في متصفح حديث. لا يحتاج إلى تثبيت أو اتصال بالإنترنت. يمكن أيضًا تشغيل `npm run serve` ثم فتح http://localhost:8080.

## الخصائص

- ١٬٠٢١ طالبة في ٢٩ شعبة: العاشر ٤٠٠، الحادي عشر ٢٨٦، الثاني عشر ٣٣٥.
- دمج قوائم متعددة؛ فرصة متساوية لكل مشاركة أو تناوب بين القوائم.
- جلسات مستقلة دون تكرار، مع التراجع عن آخر اختيار وسجل الجلسات.
- إضافة قوائم الطالبات والمعلمات بلصق عمود الأسماء من Excel.
- أربعة مظاهر، وثلاث حزم نغمات أصلية عبر Web Audio، ومستوى صوت ومعاينة وكتم.
- احتفال بصري ووضع عرض كبير، مع احترام تقليل الحركة.
- CSV للنتائج مع حماية خلايا الصيغ، ونسخ احتياطي واستعادة JSON.

## البيانات والخصوصية

القوائم من البيانات المضمنة في ملف رصد، وليست مزامنة مباشرة مع SheetDB أو الحضور. لا توجد قائمة معلمات أصلية؛ تُضاف من داخل البرنامج. المستودع خاص ويحتوي أسماء حقيقية؛ لا تنشريه أو تستضيفيه علنًا بهذه البيانات. لا توجد حسابات أو مزامنة بين الأجهزة. حفظ المتصفح قد يتعذر أو يُمسح؛ احتفظي بنسخة احتياطية. عند تغيير القوائم بعد نتائج سابقة، تبدأ جلسة جديدة وتبقى السابقة في السجل.

## بنية المشروع

`engine.js` محرك القرعة، `app.js` إدارة الواجهة والبيانات والصوت، `style.css` المظهر، `rosters.json` القوائم المنظمة، `rosters.js` نسخة تحميل محلية دون fetch، و`tests/` اختبارات المحرك.

## التحقق

`npm test` يختبر عدم التكرار، والتناوب، وتوحيد المعرفات في الدمج وسلامة تعداد القوائم. `node --check app.js` للتحقق من تركيب JavaScript. لا توجد تبعيات خارجية أو خطوط أو ملفات صوتية تحتاج الإنترنت.

## التطوير اللاحق

استيراد ملفات Excel فعليًا، تعديل وحذف المشاركات، الاستبعاد المؤقت، اختيار عدة فائزات، تشكيل الفرق وPWA يمكن إضافتها كإصدارات تالية. هذا الإصدار يدعم اللصق من Excel ولا يقرأ ملفات xlsx مباشرة.
